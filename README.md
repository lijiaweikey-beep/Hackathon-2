# Hackathon-2

移动端 3D 俯视角动作小游戏，基于 `Three.js + Vite` 开发，支持触屏虚拟摇杆与限时目标识别玩法。

## 项目亮点

- **移动端操控体验**：虚拟摇杆控制移动，单键触发攻击判定
- **双场景任务**：宿舍/网吧、图书馆，两张地图承载同一核心玩法
- **人群识别挑战**：15 个相似 NPC 随机走停漫游，增加定位难度
- **线索驱动目标锁定**：根据黑眼圈、口红印等特征识别目标 NPC
- **限次限时机制**：90 秒倒计时，3 次有效出拳机会
- **反馈完整**：命中像素块消散特效 + 胜负结算文案与动作反馈

## 技术栈

- `Three.js`：3D 场景、模型渲染与动画
- `Vite`：本地开发与构建工具
- `Firebase`：项目内联机/多人能力相关依赖（见 `src/multiplayer`）

## 快速开始

### 1) 安装依赖

```sh
npm install
```

### 2) 启动开发环境

```sh
npm run dev
```

默认会以 `0.0.0.0` 方式启动，便于局域网移动设备联调。

### 3) 生产构建

```sh
npm run build
```

### 4) 本地预览构建产物

```sh
npm run preview
```

或使用项目内静态服务脚本：

```sh
npm run serve:dist
```

## 常用脚本

| 脚本 | 说明 |
| --- | --- |
| `npm run dev` | 启动开发服务器（`0.0.0.0`） |
| `npm run build` | 构建生产包 |
| `npm run preview` | 预览构建结果（`0.0.0.0`） |
| `npm run serve:dist` | 使用 Node 脚本静态托管 `dist` |

## 目录结构（核心）

```text
src/
  config/         # 配置项
  entities/       # 玩家、NPC 等实体
  systems/        # 游戏系统逻辑
  world/          # 场景与地图逻辑
  ui/             # UI 相关模块
  multiplayer/    # 多人联机相关模块
  utils/          # 工具函数
  game.js         # 主游戏逻辑入口
```

## 开发建议

- 优先保持 `game.js` 核心流程稳定，再拆分子系统逻辑
- 新增玩法时建议同步补充 UI 状态提示与结算文案
- 若接入真实联机环境，请补充 Firebase 配置说明与部署文档
