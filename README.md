# 梗哥的半生

移动端横屏三维俯视角动作小游戏。玩家沿人生时间线从 19 岁一路打到
30 岁，主线逐关解锁，番外关卡随时可玩。

## 玩法内容

人生主线共六关：

1. 19 岁「凌晨三点打游戏」：在人群中找到熬夜目标。
2. 21 岁「图书馆抓情侣」：辨认并击中躲藏的情侣。
3. 23 岁「鹅腿夜市」：借移动路灯分辨鹅腿与发绿光的鸭腿。
4. 25 岁「超市取证」：避开货架遮挡，拍满四张证据后撤离。
5. 27 岁「躲老板黑锅」：躲开红圈落锅，一拳打爆红领带老板。
6. 30 岁「爆金币」：打晕并推入粉碎区，攒够一百金币通关。

承天寺与血月玩法保留为番外，不占用主线年龄节点。

## 核心特性

- 人生时间线逐关解锁，进度保存在本机。
- 每关拥有过场衔接，最终关完成后显示人生终章。
- 手机竖屏时强制暂停并提示旋转，恢复横屏后继续当前关卡。
- 触屏虚拟摇杆和动作按钮适配安全区域及矮屏设备。
- 关卡自动发现，经典内容玩法与独立玩法使用统一生命周期。
- 关卡目录互相隔离，支持多人并行开发。

## 本地运行

```sh
npm install
npm run dev
```

开发服务监听所有网络接口，可用同一局域网内的手机横屏访问。

## 验证命令

```sh
npm test
npm run build
```

也可预览生产构建：

```sh
npm run preview
```

## 核心目录

```text
src/

  progression/     # 主线解锁与完成进度
  runtime/         # 体验宿主、方向控制和主循环
  systems/         # 经典玩法共享系统
  ui/              # 时间线、选关与结算界面
  world/           # 经典玩法共享世界能力
tests/
  architecture/    # 模块边界约束
  levels/          # 各关规则与生命周期测试
docs/
  关卡并行开发指南.md
```
