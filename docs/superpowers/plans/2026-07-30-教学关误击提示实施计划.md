# 教学关误击提示 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 区分教学关“打到普通人物”和“没有打中人物”两种错误，并显示准确提示。

**Architecture:** 保留现有战斗动作分发，不修改共享战斗系统。教学关继续在 `hitTarget` 与 `attackMiss` 两个既有分支中决定文案，视图函数只负责展示调用方传入的提示。

**Tech Stack:** JavaScript、Node.js 内置测试运行器、Three.js、Vite。

## Global Constraints

- 打到普通人物时显示“打错人了！认准全身发光的舍友！”
- 没有打中人物时显示“没打中！靠近发光舍友并面向他出拳！”
- 不新增依赖，不修改共享战斗系统。
- 使用真实教学关人物模型覆盖回归路径。
