# 关卡强隔离与共享运行时拆分实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **给自动化开发者：** 必须使用分任务开发或计划执行流程逐项实施，并使用复选框跟踪进度。

**Goal:** 将关卡专属场景、界面、动画、音效、常量和样式完全迁入各关卡目录，并把 `game.js` 缩减为不超过 250 行的启动组装入口。

**Architecture:** 采用关卡垂直切片和稳定共享内核。关卡通过动作、扩展和分组能力上下文接入；共享运行时拆为会话、循环、角色、战斗和界面模块，不识别任何具体关卡。

**Tech Stack:** JavaScript 模块、Three.js 三维引擎、Vite 构建工具、Node.js 内置测试运行器。

## Global Constraints

- 不恢复或引用 `src/modes/duel/` 休眠双人模式。
- 不改变现有关卡玩法、数值、画风和操作手感。
- 不增加第三方依赖。
- 每项任务使用测试驱动方式：失败测试、最小实现、通过测试、完整验证、中文提交。
- 保留用户现有的 `package-lock.json` 未提交改动。
- 关卡之间不得相互导入。
- 普通关卡开发不得修改共享运行时。

---

## 文件结构

新增或重点修改的文件职责：

- `src/game.js`：最终只负责创建渲染器、相机和系统并启动。
- `src/runtime/createGameSession.js`：拥有会话状态和合法阶段转换。
- `src/runtime/createGameLoop.js`：每帧调度和渲染。
- `src/systems/createActorSystem.js`：移动、漫游、替身、分离和通用动画。
- `src/systems/createCombatSystem.js`：攻击、命中、消散和结算请求。
- `src/ui/createGameUiController.js`：选关、任务、暂停、结果和通用抬头界面。
- `src/ui/createLevelViewHost.js`：动态关卡弹层和主题。
- `src/world/createWorldBuilder.js`：只创建通用世界基础和世界能力。
- `src/levels/<关卡>/world.js`：各关卡完整场景。
- `src/levels/<关卡>/animations.js`：可选关卡动画。
- `src/levels/<关卡>/view.js`：可选关卡界面。
- `src/levels/<关卡>/audio.js`：可选关卡音效。
- `src/levels/<关卡>/constants.js`：关卡私有常量。
- `src/levels/<关卡>/styles.css`：关卡私有样式。
