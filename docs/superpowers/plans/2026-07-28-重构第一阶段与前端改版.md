# Modular Refactor Phase One and Frontend Refresh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立可测试的关卡插件化骨架、让现有关卡通过自动注册继续运行、隐藏双人入口，并将首页改造成《梗哥的半生》的暗色低多边形成长主题界面。

**Architecture:** 第一阶段不重写现有渲染和玩法。新增纯函数状态机、资源域、关卡契约、自动注册中心和关卡运行器；现有关卡先作为兼容关卡描述接入注册中心，主游戏继续使用兼容导出。双人能力保留但通过功能配置隐藏入口。

**Tech Stack:** 原生 JavaScript、Three.js、Vite、Node.js 内置测试运行器、原生 HTML 与 CSS。

## Global Constraints

- 不增加第三方依赖。
- 新关卡通过构建期自动发现，不编辑共享关卡数组。
- 关卡不得依赖页面、联机模块或其他关卡。
- 所有新增核心逻辑先写失败测试，再写最小实现。
- 保留现有单人关卡玩法和视觉表现。
- 双人入口隐藏，双人代码和带房间参数的访问能力保留。
- 每个功能提交使用中文提交信息。
- 不提交工作区中与本计划无关的既有修改。
