# 第三关监狱灯光参考实施计划

> **执行要求：** 按测试先行完成，每一步验证第三关及共享关卡无回归。

**目标：** 让“以鸭戴鹅”参考《拳击特工》监狱关卡，支持玩家踩绿色开关熄灭主灯，并在暗场中保留移动探照灯完成真假辨认。

**架构：** 灯光状态机、开关、关卡补光和探照灯光区全部放在 `goose-market/world.js`，复用世界扩展已有的 `baseLight`，不修改共享运行时。第三关逻辑每帧把玩家位置传给世界，不修改攻击与通关规则。

**技术栈：** 原生 JavaScript、Three.js、Node.js 测试运行器。

## 全局约束

- 不新增依赖。
- 熄灯由玩家踩开关触发，不做随机自动黑屏。
- 暗场仍保留探照灯和最低环境亮度。
- 鸭腿进入实际可见光区才泛绿，鹅腿始终不发光。
- 不修改其他关卡业务规则。
