# 血月关卡完整迁移 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 将血月街区的规则、状态与抬头显示迁入独立关卡插件，并删除 `src/game.js` 中的血月关卡标识判断和私有状态机。

**Architecture:** `createBloodmoonLevel(context)` 独占血月状态机，通过通用上下文能力操作角色、场景资源与反馈。关卡描述声明时间、资源和攻击外观；主循环只负责调用生命周期、执行默认移动攻击以及渲染插件返回的视图模型。

**Tech Stack:** JavaScript ES Modules、Three.js、Vite、Node.js 内置测试运行器

## Global Constraints

- 不新增运行时依赖。
- 不改变现有血月数值和流程。
- 插件不得导入 `src/game.js` 或直接访问页面元素。
- `src/game.js` 最终不得包含 `bloodmoon` 关卡标识判断。
- 保留工作区中已有的未提交移动手感修改，不得混入本轮提交。
- 每个提交必须功能完整，并使用中文提交信息。

export function isInsideSafeZone(position, zones, radius) {
  return zones.some((zone) => (
    zone && Math.hypot(position.x - zone.x, position.z - zone.z) <= radius
  ));
}

export function getBossHitTransition(mode, bossHp) {
  if (mode === "phase1") {
    return { nextMode: "huntIntro", nextBossHp: bossHp, defeated: false };
  }
  const nextBossHp = Math.max(0, bossHp - 1);
  return {
    nextMode: "phase2",
    nextBossHp,
    defeated: nextBossHp === 0,
  };
}
```

export function createBloodmoonLevel(context) {
  const state = {
    ...context.sceneData,
    mode: "phase1",
    huntTimer: 0,
    cutsceneTimer: 0,
    bossHp: BLOODMOON_PHASE2_HP_MAX,
    sanity: BLOODMOON_SANITY_MAX,
    summonWave: 0,
    nextNpcId: context.npcCount,
    huntBoss: null,
  };

  function start() {
    const target = context.createNpc(0, { bloodmoonTarget: true, levelTarget: true });
    target.levelManaged = true;
    target.group.position.copy(context.randomOpenPosition());
    initializeTargetScript(target);
    initializeNpc(target);
    context.addNpc(target);
    for (let id = 1; id < context.npcCount; id += 1) {
      const npc = context.addWanderNpc(id);
      initializeNpc(npc);
    }
  }

  return {
    start,
    update,
    handleAction,
    dispose() {
      hideSafeZones();
      context.hideOverlay("huntIntro");
      context.hideOverlay("huntCard");
    },
  };
}
```
