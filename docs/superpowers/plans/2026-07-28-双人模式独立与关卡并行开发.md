# 双人模式独立与关卡并行开发 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将双人决斗迁为不参与构建和运行的休眠独立模块，并让开发者新增不同场景、人物和预览的单人关卡时只修改自己的关卡目录。

**Architecture:** 双人模式整体下沉到 `src/modes/duel`，活动应用不再导入它。单人关卡描述直接提供世界、人物和预览扩展，公共引擎只调用稳定契约与默认实现，不识别具体关卡。

**Tech Stack:** 原生 JavaScript 模块、Three.js、Vite、Node.js 内置测试运行器。

## Global Constraints

- 保留现有单人玩法和视觉表现。
- 双人模式没有页面入口、房间链接入口和单人关卡注册入口。
- 不增加新依赖。
- 不覆盖工作区已有的双人移动手感修改；将其意图迁入休眠双人运行时。
- 每个功能提交使用中文提交信息。
- 新增关卡不需要修改主循环、注册中心、世界分派、人物分派和目标预览分派。
