# 六段年龄主线与手机横屏实施计划

> **面向执行者：** 必须逐任务使用测试驱动开发；本计划在当前会话中使用“执行计划”流程完成。

**目标：** 完成六段年龄主线、番外分组、逐关解锁、四个新增关卡和手机强制横屏适配。

**架构：** 关卡定义提供分组和年龄元数据，注册中心负责分组，独立进度模块负责解锁。前三个主线关卡使用经典运行时，后三个主线关卡使用独立体验宿主；手机方向协调属于共享应用能力，不包含任何关卡标识判断。

**技术栈：** 原生浏览器接口、JavaScript 模块、Three.js、CSS、Node.js 内置测试运行器、Vite。

## 全局约束

- 不增加第三方依赖。
- 关卡之间不得互相导入。
- 共享模块不得根据具体关卡标识分支。
- 竖屏时暂停，横屏时恢复，并清空残留输入。
- 每个功能先观察测试失败，再实现最小代码。
- 每个提交功能完整，提交说明使用中文。
- 保留用户已有的 `package-lock.json` 修改，不纳入本任务提交。

```js
export function createStoryProgress({ levels, storage, key }) {
  const ordered = [...levels];
  let completed = readCompleted(storage, key, new Set(ordered.map(({ id }) => id)));
  return Object.freeze({
    isCompleted: (id) => completed.has(id),
    isUnlocked(id) {
      const index = ordered.findIndex((level) => level.id === id);
      return index === 0 || completed.has(id) || completed.has(ordered[index - 1]?.id);
    },
    complete(id) {
      if (!ordered.some((level) => level.id === id)) return false;
      completed.add(id);
      storage.setItem(key, JSON.stringify([...completed]));
      return true;
    },
    getCompletedIds: () => [...completed],
  });
}
```
