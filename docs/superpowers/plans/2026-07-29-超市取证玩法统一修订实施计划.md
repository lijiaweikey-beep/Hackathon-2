# 超市取证玩法统一修订实施计划

> **执行要求：** 必须逐项按测试先行执行本计划，并在每个阶段验证共享关卡没有回归。

**目标：** 让超市取证复用第一关的输入与界面，只保留记忆情侣、跟随和拍摄四张照片的核心玩法。

**架构：** 独立关卡继续拥有自己的世界、目标状态机和拍照规则，但共享输入控制器与全局界面。超市只提供界面状态，不再复制任务栏、状态栏、摇杆和暂停按钮。

**技术栈：** 原生 JavaScript、Three.js、Vite、Node.js 测试运行器。

## 全局约束

- 不增加依赖，不修改其他关卡业务规则。
- 第一关与超市使用同一输入控制器和同一界面结构。
- 开局不标记主角，情侣只标记三秒。
- 情侣间距保持 0.8～1.5 个世界单位。
- 第四张有效照片立即通关。
- 删除警戒、撤离、顶部白色灯具、悬浮灯牌和红色出口条。
- 不处理手机横屏适配。
