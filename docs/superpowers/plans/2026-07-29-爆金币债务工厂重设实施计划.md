# 爆金币债务工厂重设 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将爆金币关卡重设为账单怪与房贷车贷机关的债务工厂终局体验。

**Architecture:** 将 `debt-smasher` 改为经典关卡结构，复用第一关同一套共享 HUD、摇杆、攻击按钮、角色系统和世界配置。只在关卡目录内实现债务工厂世界、账单怪角色装饰和爆金币规则。

**Tech Stack:** JavaScript ES modules, Three.js, Node test runner, Vite.

## Global Constraints

- 只修改 `src/levels/debt-smasher/`、对应测试和本次文档。
- 不修改主线进度、结算、横屏暂停、共享运行时和其他关卡。
- 不新增依赖。
- 爆金币必须走经典关卡管线，不再使用独立玩法 HUD、独立摇杆或自定义双按钮。
- 提交信息使用中文。
