# 第三关随机开关与鸭腿多目标实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **给执行者：** 必须使用“子代理驱动开发”或“执行计划”技能，按任务逐项实施；每一步用复选框跟踪。

**目标：** 第三关使用单个随机刷新开关，并要求玩家打爆本局随机生成的全部 3 至 5 个鸭腿阿姨。

**架构：** 第三关世界模块只维护开关、灯光和探照灯；第三关关卡模块只维护目标、误击惩罚和结算。通过现有关卡动作接管第三关命中与界面状态，不改共享战斗系统。

**技术栈：** 原生现代脚本模块、三维渲染库、内置测试运行器。

## 全局约束

- 玩家踩中唯一绿色开关后固定熄灯 5 秒，结束后随机换位。
- 每局等概率生成 3、4 或 5 个鸭腿阿姨，全部打爆才通关。
- 鹅腿阿姨不消失；误击提示固定为“打我鹅腿阿姨干嘛”。
- 误击仅从发生时起把下一拳最早时间从 2 秒延后到 2.5 秒，不累计。
- 挥拳次数无限，第三关不因误击耗尽次数而失败。
- 不新增依赖，不修改其他关卡规则。

```js
function placeSwitch(position) {
  const entry = switches[0];
  entry.position.copy(position);
  entry.mesh.position.set(position.x, 0.05, position.z);
  entry.ready = true;
  entry.occupied = false;
  updateSwitchAppearance(entry);
}

function updateEnvironment(deltaSeconds, playerPosition) {
  const wasBlackout = blackoutTimer > 0;
  blackoutTimer = Math.max(0, blackoutTimer - deltaSeconds);
  updateSwitch(deltaSeconds, playerPosition);
  updateLighting(deltaSeconds);
  return wasBlackout && blackoutTimer <= 0
    ? { refreshSwitch: true }
    : undefined;
}
```

触发时把熄灯计时设为 5 秒并禁用当前开关。关卡开始时调用一次 `placeSwitch`；更新收到换位事件时，使用现有随机开放位置生成能力再次放置。

```js
const duckCount = Math.floor(context.random.range(3, 6));
let remainingDucks = duckCount;
let mistakeLockTimer = 0;
let mistakeHintTimer = 0;

function handleHitTarget(hit) {
  if (hit.npc?.isDuckVendor) {
    context.actors.dissolve(hit.npc);
    context.actors.compactDead();
    remainingDucks -= 1;
    if (remainingDucks === 0) context.combat.finishLevel(true, null, 760);
    return { handled: true };
  }
  if (hit.npc?.isGoose) {
    mistakeLockTimer = 2.5;
    mistakeHintTimer = 1.5;
    return { handled: true };
  }
  return { handled: false };
}
```

第三关声明所需关卡动作；`beforeAttack` 在误击锁定剩余时间大于零时阻止出拳，否则固定返回 2 秒冷却并关闭共享连击档位。界面资源显示“剩余鸭腿”和当前数量，误击提示结束后恢复第三关线索。
