# 第三关鹅腿扩容与暗场增灯实施计划

> **执行要求：** 按顺序完成各任务；每一步完成后运行对应验证。

**目标：** 固定生成 10 个鹅腿阿姨，并在绿色开关触发的暗场期间将探照灯数量由 3 增至 5。

**架构：** 角色数量规则归属关卡创建层；探照灯状态归属场景层。场景预创建 5 组灯光资源，并以暗场状态控制后两组的可见性和强度。

---

### 任务 1：补充可执行测试

**文件：**
- 修改：`tests/levels/gooseMarketLevel.test.js`
- 修改：`tests/levels/gooseMarketWorld.test.js`

**步骤：**
1. 断言每局鹅腿角色数量为 10，鸭腿数量仍为 3–5。
2. 断言场景创建 5 组探照灯资源，平时可见 3 组，开关触发时可见 5 组，5 秒后恢复 3 组。
3. 运行 `npm test -- --run tests/levels/gooseMarketLevel.test.js tests/levels/gooseMarketWorld.test.js`，确认新增断言先失败。

### 任务 2：实现角色扩容与灯光状态

**文件：**
- 修改：`src/levels/goose-market/createLevel.js`
- 修改：`src/levels/goose-market/world.js`
- 修改：`src/levels/goose-market/definition.js`

**步骤：**
1. 使用固定常量生成 10 个鹅腿角色，再生成 3–5 个鸭腿角色，保证标识不重复。
2. 将 5 组探照灯资源预创建，并以暗场状态启用前 3 组或全部 5 组。
3. 使鸭腿照明判定仅使用启用灯位。
4. 更新关卡概览中的角色总数。

### 任务 3：回归验证与交付

**步骤：**
1. 运行本关卡测试和完整测试套件。
2. 执行生产构建。
3. 在本地页面检查正常、暗场、恢复三个阶段。
4. 审查改动后提交中文提交说明。
