# 超市取证玩法统一修订设计

> 日期：2026-07-29
>
> 状态：用户已确认
>
> 本文替代此前超市取证设计中的警戒、目标分散和出口撤离规则。

## 1. 目标

25 岁“超市取证”沿用第一关的操作手感和界面布局，只把核心动作从攻击改为拍照。
玩家仍需先通过移动在人群中找到自己，再记住并跟随开局短暂标记的目标情侣。
收集四张有效照片后立即通关。

本轮不增加主角标记，不改变拍照取证的核心判断，不处理手机横屏适配。

## 2. 核心流程

```text
开局短暂标记情侣
→ 玩家移动寻找自己
→ 标记消失，玩家凭服装记忆跟随情侣
→ 情侣结伴前往互动点
→ 玩家调整位置，让两人同时进入取景框
→ 拍摄一张有效照片
→ 情侣结伴前往下一个互动点
→ 收集四张照片后立即通关
```

倒计时结束前未完成四张照片则失败。

## 3. 操作与布局统一

### 3.1 操作手感

超市关卡复用第一关的共享输入控制器，不再自行维护另一套输入节奏。以下行为必须
与第一关同源：

- 玩家速度与移动平滑。
- 快速反向操作的锁定时间。
- 键盘与摇杆方向计算。
- 摇杆更新频率与释放行为。
- 拍照操作与第一关主操作相同的触发节流。

共享输入控制器需要支持由独立关卡的资源作用域登记事件，以便离开关卡时完整清理
监听，不允许为了复用而产生重复监听。

### 3.2 暂停按钮

暂停按钮使用第一关的共享按钮，并保持相同的右上角位置、尺寸和安全区边距。超市
倒计时显示在暂停按钮左侧，不再把暂停按钮放在底部中央。

## 4. 玩家辨识

- 不显示主角光圈、箭头或“你在这里”。
- 主角初始位于普通顾客之间，保留通过第一次移动找到自己的体验。
- 移除会遮住主角的出口悬浮横牌，确保寻找难度来自人群辨认，而不是场景穿插遮挡。

## 5. 目标情侣

### 5.1 开局标记

- 两名目标在开局显示同一组成对标识，持续三秒。
- 标识消失后，本局不再出现。
- 标记只帮助玩家记住目标，不持续导航，不改变后续追踪难度。

### 5.2 移动规则

- 两名目标始终结伴移动，间距保持在 0.8～1.5 个世界单位。
- 两人共同前往同一个合法互动区域，不再向两个远距离位置分散。
- 每次拍摄成功或互动超时后，两人一起前往下一个互动点。
- 全程使用共享角色移动、避障和步行动画，不允许瞬移。

## 6. 拍照与通关

有效照片继续同时满足：

- 目标正处于互动阶段。
- 两名目标同时位于玩家前方取景角度内。
- 玩家与两名目标的距离符合要求。
- 玩家到两名目标的视线都没有被货架或柜台遮挡。
- 当前互动事件尚未被拍摄。

成功拍照继续播放举相机、对焦、快门闪光和证据卡片动画。失败拍照只显示一个明确
原因，例如目标未互动、未同时入镜、视线被挡或距离太远。

第四张有效照片完成时立即成功结算。删除出口开放、出口触发区域和撤离阶段。

## 7. 删除警戒

警戒不参与本关的核心“记忆目标、跟随、构图、拍摄”循环，本轮完整删除：

- 警戒数值与增长、衰减计算。
- 目标观察玩家的视线判断。
- 安全、注意、危险状态。
- 警戒满值失败条件。
- 警戒界面、说明和相关文案。

失败条件只保留倒计时耗尽，以及有效拍摄机会不足。

## 8. 界面信息

游戏中只保留必要信息：

- 左上角：照片进度。
- 右上角：倒计时和共享暂停按钮。
- 画面中央：当前操作提示与取景框。
- 左下角：共享手感的移动摇杆。
- 右下角：拍照按钮。

当前操作提示按阶段切换，且同一时间只显示一句：

1. 开局：“记住标记的两名目标，移动寻找自己。”
2. 追踪：“跟随刚才标记的情侣。”
3. 互动：“让两人同时进入取景框。”
4. 可拍：“目标已入镜，立即拍照。”

## 9. 文件边界

- `src/systems/createInputController.js`：补充可清理的事件登记方式，经典关卡行为保持不变。
- `src/levels/supermarket/createExperience.js`：组合共享输入、阶段提示、拍照动画和四张即结算。
- `src/levels/supermarket/targetSequence.js`：开局标记计时与情侣结伴移动状态。
- `src/levels/supermarket/rules.js`：保留拍照有效性，删除出口规则。
- `src/levels/supermarket/world.js`：移除悬浮横牌和出口玩法资源，提供开局成对标识。
- `src/levels/supermarket/styles.css`：删除警戒与出口样式，整理必要信息布局。
- `src/styles.css`：让独立关卡暂停按钮回到第一关的右上角共享位置。

不新增依赖，不重写共享角色系统，不修改其他关卡业务规则。

## 10. 验收标准

- 第一关与超市关卡使用同一输入控制器，快速转向、摇杆和主操作节奏一致。
- 两关暂停按钮的位置、尺寸和安全区边距一致。
- 开局没有主角标记，玩家仍需通过移动找到自己。
- 目标情侣只在开局标记三秒，后续不再显示标记。
- 目标情侣始终结伴移动，间距保持在 0.8～1.5 个世界单位。
- 遮挡玩家的悬浮横牌消失，人物不会穿过货架、柜台或墙体。
- 警戒界面、警戒计算和警戒失败条件全部删除。
- 每次互动最多记录一张有效照片，失败原因明确。
- 第四张有效照片完成后立即成功，不再要求撤离。
- 倒计时耗尽或有效拍摄机会不足会正常失败。
- 相关单元测试、全量测试、生产构建和浏览器实际游玩验证全部通过。
