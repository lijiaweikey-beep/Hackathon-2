# 第四关随机姿势潜行取证设计

> 日期：2026-07-29
>
> 状态：已确认

## 1. 目标

把二十五岁“超市取证”从重复等待并拍摄四张相同照片，改造成一关短流程的
潜行跟拍玩法。玩家需要尾随目标情侣、利用货架躲避视线，并分别拍到牵手、
拥抱和亲吻三种证据，最后安全撤离超市。

本轮设计坚持以下原则：

- 仍然只使用移动和拍照两个操作。
- 难度来自跟踪、躲藏、拍摄位置和时机，不依赖苛刻倒计时。
- 三种姿势随机出现，但必须有保底，不能因连续重复而拖延通关。
- 提示负责说明规则和当前状态，不直接替玩家完成取景判断。

## 2. 不在本轮范围

- 不增加购物车、拿商品或假装挑选等额外伪装操作。
- 不为三种姿势分别增加不同的距离、角度或构图规则。
- 不增加照片评分、连拍、相机升级或证据品质系统。
- 不改变其他主线关卡和番外关卡。

## 3. 核心流程

一局流程为：

```text
开局短暂标记目标情侣
→ 保持距离尾随
→ 目标回头时利用货架躲避
→ 观察随机出现的未取证姿势
→ 离开掩体寻找无遮挡拍摄位置
→ 完成拍摄并继续跟随
→ 收齐牵手、拥抱、亲吻三张证据
→ 出口开启
→ 抵达出口通关
```

回合继续使用九十秒上限。漏拍一次姿势不会直接消耗永久机会，玩家仍可等待
该姿势再次出现。失败只来自超时或被目标彻底发现。

## 4. 三种姿势与保底随机

证据固定为：

1. 牵手。
2. 拥抱。
3. 亲吻。

每次准备互动时，从尚未成功取证的姿势中随机选择一种。成功拍摄后，该姿势
从候选集合中移除，因此一局内三张成功照片必定不同。

如果玩家漏拍或拍摄无效，该姿势仍保留在候选集合中，后续可以再次随机出现。
当只剩一种未取证姿势时，后续互动固定重复该姿势，直到玩家拍到或回合结束。

已经成功取证的姿势不再出现，避免玩家等待无用的重复事件。随机性只改变三种
姿势的出现顺序和互动地点，不改变完成任务所需的有效照片数量。

## 5. 姿势表现

低多边形俯视人物难以表达细小动作，因此三种姿势必须使用不同且夸张的动画：

- 牵手：两人并排移动，靠近的手臂向中间伸出并保持连接。
- 拥抱：两人面对面靠近，双臂前伸包围对方。
- 亲吻：两人头部靠近，短暂出现小型爱心效果。

每次姿势持续约三至四秒。姿势开始前，两人先减速并靠近，给玩家预判和调整
拍摄位置的时间。

三种姿势使用相同的拍摄有效性规则，不要求玩家记忆额外参数。

## 6. 潜行与暴露

情侣在前往下一互动点的途中会周期性回头。回头前必须依次提供：

1. 行走速度下降。
2. 头部开始转动。
3. 短暂出现疑问提示。
4. 视线区域由透明变为黄色。

只有正式回头后，玩家处于视线范围、与目标无遮挡且距离过近时，暴露值才增长。
躲到货架后或离开危险距离后，暴露值逐渐下降。

暴露值达到上限时记为一次警觉：

- 第一次警觉：情侣取消当前互动、分开并改变路线。
- 第二次警觉：回头频率提高，互动持续时间略微缩短。
- 第三次警觉：情侣离开超市，本局失败。

警觉次数在顶部以三个清晰状态格显示，避免玩家误解连续暴露值和累计惩罚的关系。

## 7. 拍照规则

有效照片同时满足：

- 当前目标正在进行尚未取证的姿势。
- 两名目标同时进入取景范围。
- 玩家与两名目标之间均没有货架或收银台遮挡。
- 玩家位于统一有效距离内。
- 玩家朝向覆盖两名目标。

三种姿势使用同一距离和朝向阈值。按下拍照后，玩家停顿约半秒完成举机和对焦，
期间不能移动。该停顿使拍照成为需要承担暴露风险的决定。

拍摄无效不会移除当前姿势，也不会扣除永久拍照机会，但快门声会增加少量暴露值，
防止连续乱拍。

取消当前“取景框变亮就一定成功”的直接答案。取景框只根据对焦程度轻微收紧，
不显示“可以拍照”文字。

## 8. 提示与反馈

顶部长期显示三格证据清单：

```text
牵手 □　拥抱 □　亲吻 □
```

姿势开始时短暂显示：

```text
发现新动作：拥抱 · 尚未取证
```

拍摄成功后，对应证据格勾选，并显示：

```text
拥抱证据已保存 · 证据 2/3
```

拍摄失败时只显示最优先的一条原因，优先顺序为：

1. 当前没有有效姿势。
2. 两名目标没有同时入镜。
3. 视线被货架或收银台遮挡。
4. 距离太远。
5. 朝向不正确。

一次只展示一个原因，避免玩家同时处理多条提示。

## 9. 撤离

第三张证据拍摄成功后不立即结算。情侣进入发现异常后的搜索状态，出口由红色变为
绿色，并显示“证据齐全，立即撤离”。

玩家抵达底部收银区域的出口后通关。暴露规则在撤离阶段继续生效，第三次警觉仍会
导致失败。撤离阶段不再生成新的姿势。

## 10. 模块边界

第四关继续保持独立玩法结构，并把职责拆分为小型模块：

- 姿势序列：管理未取证姿势集合、保底随机、互动时间和移动阶段。
- 潜行规则：计算视线、暴露值、警觉次数和失败状态。
- 拍照规则：判断姿势、入镜、遮挡、距离和朝向，记录证据。
- 场景世界：提供货架、互动点、出口、遮挡查询和人物对象。
- 体验编排：连接输入、规则、人物动画、界面反馈和结算，不承载具体判定细节。

共享运行时不添加第四关专属判断，其他关卡不导入第四关模块。

## 11. 状态流转

目标情侣状态为：

```text
前往互动点
→ 回头预警或正常移动
→ 执行随机姿势
→ 成功取证、漏拍或被打断
→ 前往下一互动点
```

三张证据收齐后进入撤离状态，不再回到互动循环。

拍照状态为：

```text
按下拍照
→ 玩家短暂停步
→ 校验当前场景
→ 成功保存证据或返回单一失败原因
→ 增加对应反馈和暴露
```

## 12. 异常与保底

- 互动点必须至少存在两个无遮挡的有效拍摄位置。
- 随机选择互动点时避免连续使用同一位置。
- 玩家错过姿势后不扣除永久机会。
- 只剩一个未取证姿势时固定重复该姿势。
- 暂停、切换横竖屏或离开页面时停止计时、姿势动画和暴露增长。
- 恢复游戏时沿用暂停前状态，不重新随机当前姿势。

## 13. 测试与验收

### 自动测试

- 三种姿势的首次出现顺序随机。
- 成功取证的姿势不会再次进入候选集合。
- 漏拍姿势仍可再次出现。
- 只剩一种姿势时会持续获得该姿势。
- 重复或无效照片不会增加证据数量。
- 三种姿势使用相同的遮挡、距离和朝向规则。
- 货架遮挡时不增加暴露，无遮挡且过近时增加暴露。
- 三次警觉失败，前两次仍可继续游戏。
- 三张证据只开启出口，抵达出口后才成功。
- 暂停和恢复不会重置证据、姿势、暴露或警觉状态。

### 浏览器验收

- 玩家能在一局内明确理解要收集三种不同姿势。
- 三种姿势在俯视角和手机横屏下可以快速区分。
- 顶部证据格、当前姿势和警觉状态不遮挡主要场景。
- 回头前有足够预警，货架可以可靠阻断视线。
- 无效照片只显示一个准确原因。
- 第三张照片后出口反馈明显，并能完成撤离。
- 随机种子变化时姿势顺序和互动地点会变化，但每局均可完成。

## 14. 完成标准

- 第四关目标改为三张不同姿势证据。
- 保底随机不存在重复已取证姿势或缺少最后姿势的问题。
- 潜行、拍照、警觉和撤离形成完整闭环。
- 自动测试、构建和浏览器实机验证全部通过。
- 不影响其他主线关卡和番外关卡。
