# 《梗哥的半生》游戏设计方案

> 版本：1.0
>
> 日期：2026-07-28
>
> 定位：三维俯视角、单人叙事、观察伪装与一拳解压游戏

## 1. 产品概述

### 1.1 一句话介绍

梗哥混在人群中，装作若无其事，找出那些让人憋屈的家伙，然后一拳打爆。

### 1.2 核心宣传语

> 人生是旷野，先把这半生的破事打爆。

### 1.3 目标体验

玩家在每关经历完整的情绪循环：

```text
先忍耐
→ 再观察
→ 确认目标
→ 伪装接近
→ 一拳爆发
→ 环境恢复
```

最终感受不是“打赢了一个敌人”，而是“把被生活拿走的东西重新夺了回来”。

### 1.4 产品形态

| 项目 | 定义 |
| --- | --- |
| 游戏类型 | 三维俯视角观察动作游戏 |
| 主模式 | 单人叙事闯关 |
| 操作平台 | 移动端浏览器、电脑浏览器 |
| 单关时长 | 普通关四十五至六十秒 |
| 完整流程 | 十二至十五分钟 |
| 目标玩家 | 对校园、研究生、职场和家庭压力有共鸣的年轻玩家 |
| 核心传播点 | 现实吐槽、一拳解压、结算梗图、人生阶段共鸣 |

## 2. 设计原则

### 2.1 找人的方式一直变，出拳方式永远不变

每关只改变：

- 人群遵守什么规则。
- 目标如何暴露异常行为。
- 玩家如何在不惊动目标的情况下靠近。
- 打错后环境如何恶化。
- 打对后什么东西得到恢复。

玩家操作始终只有移动和出拳。

### 2.2 观察重于操作

游戏难点来自：

- 找到自己控制的角色。
- 理解本关人群行为。
- 识别目标的异常动作。
- 记住目标混回人群后的路线。
- 选择安全的接近时机。

不依赖复杂连招、反应速度或角色数值。

### 2.3 永远一拳解决

- 目标没有血条。
- 不需要连续攻击。
- 不设计武器、技能和装备。
- 正确目标一拳打爆。
- 研究生关等长关卡通过连续识别多个目标增加难度，而不是增加目标血量。

### 2.4 先制造憋屈，再给予释放

目标的烦人行为必须真实影响场景：

- 体育器材变成试卷。
- 下课时钟不断倒退。
- 宿舍噪音越来越大。
- 学生署名被导师拿走。
- 临时任务文件不断增加。

正确命中后，上述影响必须被明显逆转。

### 2.5 夸张但不写实

- 所有攻击采用卡通击飞、拉伸、旋转和像素碎裂。
- 不使用血液、伤口或写实受伤表现。
- 重点攻击荒唐行为及其象征物，而不是塑造真实暴力。

## 3. 核心玩法

### 3.1 标准关卡循环

### 阶段一：确认自己

开局不显示梗哥头顶标记。玩家轻推方向，通过人群中哪个角色产生响应，判断自己控制的是谁。

教学关允许较明显的移动反馈；后续关卡逐渐减少辅助。

### 阶段二：模仿人群

每个场景都有统一的人群行为，例如：

- 听哨声跑步、停下、转向。
- 下课铃响后合书、收拾书包。
- 地铁转弯时向同一侧倾斜。
- 下班时保存文件、关电脑、走向电梯。
- 饭桌上统一夹菜、敬酒和合照。

玩家应跟随这些行为，避免显得异常。

### 阶段三：观察目标

目标会周期性做出烦人行为。行为本身就是线索，不显示直接指向目标的箭头或长期发光标记。

目标完成行为后会重新混回人群，玩家需要记住其位置和移动方向。

### 阶段四：伪装接近

当玩家在目标附近表现异常时，目标会警觉：

- 转头观察梗哥。
- 暂停当前烦人行为。
- 与其他角色交换位置。
- 移动到新的活动区域。
- 延迟下一次破绽。

玩家需要继续模仿人群，利用集体移动和场景遮挡接近目标。

### 阶段五：一拳爆发

正确命中后立即结束关卡，并进入专属释放演出。

### 3.2 基础参数

| 参数 | 普通关 | 研究生关 | 最终章 |
| --- | ---: | ---: | ---: |
| 时长 | 六十秒 | 九十秒 | 不限 |
| 误伤机会 | 三次 | 三次，共用 | 不限 |
| 正确目标 | 一至三个 | 三个连续目标 | 十组目标 |
| 正确命中 | 不扣机会 | 不扣机会 | 不限出拳 |
| 失败条件 | 时间结束或误伤三次 | 时间结束或误伤三次 | 无失败 |

### 3.3 统一误伤结果

误伤后：

1. 被误伤角色滑稽飞走。
2. 梗哥短暂暴露位置。
3. 真正目标出现偷笑、回头或庆幸动作。
4. 目标立即换位。
5. 人群短暂混乱后重新排列。
6. 消耗一次误伤机会。

误伤不立即弹出结算，以免打断体验节奏。

## 4. 关卡与叙事结构

| 章节 | 关卡 | 核心训练 |
| --- | --- | --- |
| 学生时代 | 消失的体育课 | 找到自己、模仿简单动作 |
| 学生时代 | 再耽误两分钟 | 等待行为破绽 |
| 学生时代 | 自愿留校 | 追踪移动目标 |
| 大学时代 | 凌晨三点 | 声音定位 |

| 大学时代 | 以鸭戴鹅 | 遮挡与多证据确认 |
| 研究生时代 | 毕业保卫战 | 连续综合识别 |
| 社会阶段 | 烟雾与噪音 | 双目标和环境节奏 |

| 最终章 | 去你的轨道 | 纯粹情绪释放 |

## 5. 详细关卡设计

### 5.1 小学：《消失的体育课》

### 关卡定位

教学关，只教授：

- 找到自己。
- 跟随集体动作。
- 观察目标破绽。
- 靠近并出拳。

### 场景

操场上有十二名学生、体育老师和三名相似的主课老师。

### 人群行为

哨声控制学生：

1. 第一声哨响，学生统一跑步。
2. 第二声哨响，学生统一停下。
3. 第三声哨响，学生统一转向。

### 目标破绽

目标老师每隔八秒走向一件体育器材，将篮球、跳绳或球门变成试卷和课桌。

### 玩家决策

玩家不能直接逆着学生队伍冲向老师，需要跟随队伍绕到目标附近，在目标转换器材时出拳。

### 误伤恶化

- 一件体育器材永久变成课桌。
- 操场活动范围缩小。
- 目标老师移动到另一侧。

### 通关演出

目标撞碎一排课桌，试卷炸成纸屑，体育器材全部恢复，操场重新变得鲜艳。

> 这一拳，把体育课还回来。

### 5.2 初中：《再耽误两分钟》

### 关卡定位

引入“等待统一事件发生后再判断目标”。

### 场景

已经响过下课铃的教室，有多名相似老师和学生。

### 人群行为

铃声响起后，学生依次：

1. 合上课本。
2. 收拾书包。
3. 起身。
4. 走向门口。

### 目标破绽

只有目标老师会在下课铃后继续写黑板，并出现“再耽误大家两分钟”的气泡。随后墙上时钟倒退。

### 玩家决策

玩家要在起身的人群中记住目标老师，再利用学生移动形成的遮挡靠近。

### 误伤恶化

- 时钟倒退两分钟。
- 门口增加一排课桌。
- 学生重新换座。

### 通关演出

目标撞穿黑板，粉笔和钟表一起碎裂，教室门完全打开。

> 这一拳，把课间十分钟还回来。

### 5.3 高中：《自愿留校》

### 关卡定位

引入人流追踪和逆向行为识别。

### 场景

夕阳下的学校门口，学生不断向校门移动，多名老师站在人群中。

### 人群行为

- 学生统一向校门前进。
- 校门拥堵时停下。
- 放行后继续移动。

### 目标破绽

目标老师会：

1. 逆着人流移动。
2. 拦住准备离校的学生。
3. 掏出申请表。
4. 盖上“自愿留校”印章。
5. 重新混回教师人群。

### 玩家决策

玩家需要顺着人流接近目标，不能长时间逆行或直接追逐。

### 误伤恶化

- 校门增加一道围栏。
- 更多学生被赶回教室。
- 目标下一次盖章时间缩短。

### 通关演出

目标撞碎围栏和印章，校门打开，学生集体冲向夕阳。

> 这一拳，把选择权还回来。

### 5.4 大学宿舍：《凌晨三点》

### 关卡定位

引入声音定位和黑暗环境。

### 场景

熄灯后的大学宿舍，有多个床位和遮挡帘。

### 人群行为

熄灯后所有室友保持静止。梗哥只能借助外放音乐、键盘声和窗外雷声掩盖脚步。

### 目标破绽

- 键盘快速敲击。
- 手机突然外放。
- 显示器短暂照亮面部。
- 音源随目标位置改变方向。

其他室友可能看手机，但不会外放。

### 玩家决策

先听声音确定大致方向，再等待屏幕闪光确认具体床位，最后借噪音掩护接近。

### 误伤恶化

- 被打醒的室友也会打开手机。
- 场景出现更多屏幕光。
- 增加新的提示音干扰。

### 通关演出

目标撞穿电脑桌，键盘、音箱和显示器连续爆炸，宿舍瞬间安静。

> 这一拳，让全宿舍睡个好觉。

### 5.5 图书馆：《旁若无人》

### 关卡定位

引入双人关系识别。

### 场景

图书馆内有多组读者，有些人在讨论、递书或并排学习。

### 人群行为

管理员巡视时：

- 所有读者低头。
- 停止交流。
- 保持安静。

玩家也必须停止快速移动。

### 目标破绽

管理员转身后，目标情侣会短暂靠近，并出现微弱爱心和口红印。

普通读者虽然可能靠得很近，但只会传书或讨论题目。

### 玩家决策

不能只根据距离判断，必须观察两人的互动关系。攻击其中任意一人即可命中整组目标。

### 误伤恶化

- 读者重新换座。
- 目标情侣暂时分开。
- 管理员巡视速度加快。

### 通关演出

一拳产生连锁冲击，两人分别飞进左右书堆，图书馆重新安静。

> 这一拳，把图书馆还给读书的人。

### 5.6 大学校门：《以鸭戴鹅》

### 关卡定位

引入遮挡和多证据确认。

### 场景

大学校门外有四个相似摊位，大量学生排队购买烤腿。

### 人群行为

顾客随队伍前进：

1. 摊主递出食物。
2. 第一位顾客离开。
3. 后面所有人向前移动一格。

玩家不能插队，否则目标摊主会警觉并交换位置。

### 目标证据

目标摊位有三个短暂证据：

- 招牌从“鹅”闪成“鸭”。
- 烤腿影子露出鸭掌。
- 递餐时出现一声鸭叫。

看到任意两个证据即可可靠确认。

### 误伤恶化

- 顾客数量增加。
- 摊主交换摊位。
- 招牌闪烁时间缩短。

### 通关演出

目标撞穿假招牌，摊位炸开，鸭腿和纸屑飞满天空。

> 这一拳，还给大家真材实料。

### 5.7 研究生：《毕业保卫战》

### 关卡定位

中期综合考验。九十秒内完成三个连续小回合，共用三次误伤机会。

### 第一回合：论文造假

- 所有研究人员轮流展示数据图。
- 目标屏幕会复制完全相同的图表并修改数字。
- 确认目标后打出第一拳。

### 第二回合：导师抢成果

- 论文作者姓名会在角色之间移动。
- 目标导师会趁学生转身时，将金色第一作者姓名拖到自己头顶。
- 记住目标，混入会议人群接近，打出第二拳。

### 第三回合：恶意延毕

- 多名导师拿着不同印章。
- 目标会藏起毕业章、撕掉申请表并关闭毕业出口。
- 确认后打出最后一拳。

### 通关演出

- 假数据碎裂。
- 学生姓名回到论文第一位。
- 毕业章飞回学生手中。
- 毕业大门打开。
- 学位帽飞满天空。

> 这一拳，把成果、名字和毕业证一起拿回来。

### 5.8 上班通勤：《烟雾与噪音》

### 关卡定位

连续识别两个不同类型的目标。

### 场景

拥挤的地铁车厢。

### 人群行为

地铁转弯、加速和刹车时，所有乘客统一向对应方向倾斜。玩家需要跟随车厢节奏移动。

### 第一目标：抽烟者

- 烟雾在人群中移动。
- 目标每隔数秒吐出一次烟圈。
- 烟圈出现后，目标立即换位。

### 第二目标：手机外放者

- 多人都拿着手机。
- 只有目标手机随音乐节奏闪光。
- 声音方向可以辅助判断。

### 误伤恶化

- 烟雾变浓。
- 音乐加入更多杂音。
- 到站后人群重新排列。

### 通关演出

两个目标分别撞碎禁烟牌和外放音箱，烟雾散去，车厢恢复安静。

> 这一拳，还给大家空气和安静。

### 5.9 职场：《最后一分钟》

### 关卡定位

在时间压力下保持观察与伪装。

### 场景

时间停在十七点五十九分的办公室。

### 人群行为

所有员工依次：

1. 保存文件。
2. 关闭电脑。
3. 拿起背包。
4. 走向电梯。

玩家必须装成正常下班的员工。

### 目标破绽

领导会逆着下班人流行动，突然掏出红色文件夹，走向某位员工。玩家表现得过于着急时，领导会收起文件夹并换位。

### 误伤恶化

- 时钟倒退五分钟。
- 办公桌上增加红色文件夹。
- 同事重新分配工位。

### 通关演出

目标撞穿考勤机，红色文件夹爆炸，所有任务飞出窗外，时钟跳到十八点。

> 这一拳，把下班时间还给自己。

### 5.10 回家过年：《催婚围攻》

### 关卡定位

普通关卡的最终快速识别考验。

### 场景

过年家庭饭桌，十名亲戚不断换座、夹菜和敬酒。

### 人群行为

- 敬酒时全员起身。
- 夹菜时身体转向饭桌。
- 合照时全员面向镜头。

玩家需要模仿这些动作，避免过早暴露。

### 目标破绽

每轮只有一位亲戚停止集体动作，转向梗哥提出：

- 有对象了吗？
- 工资多少？
- 什么时候结婚？
- 准备要孩子了吗？

问题气泡只出现一秒，随后提问者重新混入人群。

### 通关条件

连续找出并击中三名催婚亲戚。

### 误伤恶化

- 新增一名亲戚。
- 饭桌活动范围缩小。
- 下一个问题出现得更快。

### 通关演出

第三拳命中后触发连锁冲击，剩余催婚亲戚像多米诺骨牌一样全部飞出画面。

> 这一拳，我的人生我自己安排。

## 6. 最终章：《去你的轨道》

### 6.1 定位

最终章是奖励关，只负责情绪释放，不再考验玩家。

### 6.2 规则

- 不限时间。
- 不限出拳。
- 没有误伤。
- 没有失败。
- 玩家亲手完成每一次出拳。

### 6.3 流程

前十关目标依次出现在灰色轨道上。玩家每按一次出拳：

- 一个目标慢镜头飞出画面。
- 一段轨道碎裂。
- 世界恢复一种颜色。
- 音乐节奏逐渐加快。

最后出现由所有烦人话术组成的巨大“忍一忍”。

玩家按住出拳蓄力，松开后完成最终一击。“忍一忍”碎裂，轨道变成草地和天空。

### 6.4 最终文案

> 这半生，他们拿走了你的操场、课间、选择、睡眠、成果和时间。
>
> 现在，把自己一样一样打回来。
>
> **人生是旷野，不是轨道。**

## 7. 爽感与反馈规范

正确出拳必须依次包含：

1. 命中瞬间短暂停顿。
2. 镜头快速推近。
3. 背景声音短暂消失。
4. 重击声与低频震动出现。
5. 目标身体拉伸、旋转、飞出。
6. 目标连续撞碎两至三个场景物件。
7. 烦人事物全部消失。
8. 场景从灰暗恢复鲜艳。
9. 人群出现鼓掌、欢呼或松一口气的动作。
10. 出现本关专属文案。

核心验收标准：

> 玩家打爆的不只是目标，也是目标造成的压抑环境。

## 8. 角色成长表现

梗哥在不同阶段保持相同脸型和标志性色彩，通过服装体现成长：

| 阶段 | 造型 |
| --- | --- |
| 小学 | 红领巾、小书包 |
| 初中 | 宽大校服 |
| 高中 | 试卷袋、厚眼镜 |
| 大学 | 拖鞋、黑眼圈 |
| 研究生 | 格子衫、论文文件夹 |
| 职场 | 工牌、公文包 |
| 过年 | 节日服装、被亲戚包围 |

## 9. 界面与流程

### 9.1 主流程

```text
标题页
→ 人生时间轴
→ 关卡简报
→ 找到自己
→ 伪装观察
→ 正确出拳
→ 专属恢复演出
→ 结算
→ 下一人生阶段
```

### 9.2 游戏界面

只保留：

- 当前关卡名称。
- 简短任务目标。
- 剩余时间。
- 剩余误伤机会。
- 出拳按钮。

不显示：

- 目标箭头。
- 长期高亮。
- 复杂小地图。
- 生命值。
- 技能栏。
- 装备栏。

## 10. 结算与复玩

### 10.1 单关结算

显示：

- 通关时间。
- 误伤人数。
- 观察过的破绽次数。
- 是否首次出拳命中。
- 本关夺回的事物。

示例：

> 本次夺回：下班时间
>
> 用时：28.6 秒
>
> 误伤同事：0 人
>
> 评价：精准出拳

### 10.2 评价规则

| 评价 | 条件 |
| --- | --- |
| 最高评价 | 无误伤，较短时间内完成 |
| 优秀评价 | 一次误伤或使用较长时间 |
| 普通评价 | 两次误伤后完成 |
| 失败 | 三次误伤或时间结束 |

### 10.3 分享内容

结算页可生成分享图：

> 十七点五十九分，我一拳打爆了临时任务。
>
> 误伤同事：0 人。
>
> 你能比我更快吗？

后续扩展：

- 每日固定人群布局。
- 同一布局挑战好友。
- 百人高难度模式。
- 随机烦人事件组合。

## 11. 视觉与音频方向

### 11.1 视觉

- 延续低多边形三维俯视角。
- 角色轮廓统一，便于混入人群。
- 每个场景拥有一个高辨识度色彩主题。
- 目标未暴露时不使用特殊颜色。
- 场景在压抑阶段降低饱和度，正确命中后恢复鲜艳。
- 爆炸采用几何块、纸屑、道具和文字碎片。

### 11.2 音频

- 人群行为由清晰的环境音提示。
- 声音定位关必须提供可靠的左右方向反馈。
- 出拳前短暂抽掉环境声。
- 命中使用低频重击、碎裂和人群反应三层声音。
- 通关音乐从压抑节奏切换为轻快旋律。

## 12. 系统拆分

为避免主游戏文件继续膨胀，建议拆分为以下独立模块：

| 模块 | 责任 |
| --- | --- |
| 游戏流程管理 | 关卡开始、暂停、胜负、结算、切换 |
| 人群行为系统 | 集体动作、路径、停顿、重新排列 |
| 玩家伪装判断 | 玩家是否遵循人群行为、目标警觉 |
| 目标行为系统 | 周期性烦人行为、显形、换位 |
| 出拳判定系统 | 范围、朝向、正确目标、误伤 |
| 爽感演出系统 | 停顿、震屏、击飞、碎裂、环境恢复 |
| 关卡配置 | 人数、行为、目标、线索、惩罚和文案 |
| 结果统计 | 时间、误伤、破绽次数和评价 |

每个关卡通过配置描述：

- 场景。
- 人群数量。
- 集体行为。
- 目标行为。
- 行为周期。
- 警觉条件。
- 误伤后果。
- 通关演出。
- 结算文案。

禁止将十个关卡全部写成主循环中的独立条件分支。

## 13. 开发优先级

### 第一阶段：核心验证

先制作三个代表性关卡：

1. 《消失的体育课》：验证集体行为、找到自己和基础出拳。
2. 《凌晨三点》：验证声音定位和黑暗场景。
3. 《最后一分钟》：验证伪装接近和情绪释放。

通过标准：

- 新玩家十秒内理解移动和出拳。
- 新玩家三十秒内理解人群规则。
- 正确出拳后能明确说出“爽”或产生明显笑声。

### 第二阶段：内容扩展

- 完成初中、高中、图书馆、假鹅腿和通勤关卡。
- 配置化共用行为和提示。
- 完善误伤与目标警觉系统。

### 第三阶段：完整叙事

- 完成研究生和催婚关卡。
- 完成人生时间轴。
- 完成最终章。
- 完成结算分享图。

## 14. 验收标准

### 14.1 可玩性

- 玩家全程只需要移动和出拳。
- 每关在十秒内展示一次人群规则。
- 目标破绽可以通过行为可靠判断。
- 不存在必须猜测才能完成的目标。
- 正确目标始终一拳解决。
- 普通关卡控制在四十五至六十秒。

### 14.2 爽感

- 正确命中拥有可感知的停顿、震动、击飞和碎裂。
- 目标造成的环境问题必须同步消失。
- 通关后场景色彩和声音明显改善。
- 最终章没有失败和误伤。

### 14.3 叙事

- 每关明确表现梗哥被拿走了什么。
- 每关结算明确表现梗哥夺回了什么。
- 关卡顺序形成从校园到社会的人生时间轴。
- 最终文案能够自然落到“人生是旷野，不是轨道”。

### 14.4 技术

- 人群数量增加时保持稳定运行。
- 目标换位后仍可可靠追踪和判定。
- 出拳判定不会击中身后角色。
- 场景切换后不存在旧角色、旧音效或旧计时器残留。
- 关卡配置与底层系统保持解耦。

## 15. 风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 找到自己过难 | 玩家开局迷茫 | 教学关提供短暂脚底波纹，后续逐步取消 |
| 目标线索过弱 | 玩家认为只能猜 | 每个目标至少提供两种一致证据 |
| 目标线索过强 | 观察玩法失去意义 | 线索短暂出现，目标随后换位 |
| 每关开发成本过高 | 无法按期完成 | 复用四套场景和五类行为系统 |
| 一拳反馈不够爽 | 核心卖点失败 | 将停顿、推镜、重击、击飞、碎裂和环境恢复列为必做 |
| 现实题材引发不适 | 传播风险 | 角色卡通化，攻击荒唐行为，不使用真实姓名和肖像 |
| 主文件继续膨胀 | 后续维护困难 | 按流程、人群、目标、出拳、演出和配置拆分模块 |

## 16. 最小可演示版本

最小演示版本只包含：

- 《消失的体育课》。
- 《凌晨三点》。
- 《最后一分钟》。
- 一个简化版最终章。

演示顺序：

```text
小学的兴趣被拿走
→ 大学的睡眠被拿走
→ 职场的时间被拿走
→ 最终把自己打回来
```

如果这三个关卡不能分别验证视觉观察、声音判断和情绪释放，则不继续生产其余场景。
